# Portfolio Site

Интерактивное 3D-портфолио в стиле «езда на машинке по миру» — Three.js, без сборки.

- `index.html` — разметка, HUD, инфо-панель, importmap для Three.js (CDN)
- `style.css` — интерфейс: загрузчик, подсказки, панель проекта, мобильные контролы
- `script.js` — сцена, физика машинки, трамплины, точки интереса

Управление: **WASD / стрелки** — ехать, **Ctrl** — сигналить. На мобильных — экранные кнопки.

Запуск локально: `python3 -m http.server` (или любой статический сервер) — нужен интернет для CDN Three.js.
