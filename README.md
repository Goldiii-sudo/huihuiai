# Portfolio Site

Одностраничное портфолио на ванильном HTML/CSS/JS — без сборки и зависимостей.

- `index.html` — разметка
- `style.css` — стили и анимации
- `script.js` — прелоадер, кастомный курсор, скролл-эффекты, tilt-карточки

Запуск локально: открыть `index.html` в браузере или `python3 -m http.server`.
